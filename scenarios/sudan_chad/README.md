# Historical Validation of FLEE for Sudan–Chad Displacement

## Project Overview

This project evaluates the ability of the FLEE agent-based forced-displacement modelling framework to reproduce historically observed displacement patterns from Sudan into eastern Chad during the 2023 Sudan conflict.

The study uses publicly available humanitarian displacement data, primarily from UNHCR, and compares historical observations with simulated refugee distributions generated by FLEE.

The principal validation locations are:

- Ouaddaï
- Sila
- Wadi Fira

Two historical validation checkpoints are used:

- 3 July 2023
- 6 September 2023

The final model is referred to as **Topology V3**.
